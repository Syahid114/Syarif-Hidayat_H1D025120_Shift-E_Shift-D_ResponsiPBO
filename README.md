## Petunjuk Compile dan Run

- Java Development Kit (JDK) telah terpasang.
- Terminal atau Command Prompt dapat digunakan untuk menjalankan perintah Java.

Periksa instalasi Java dengan perintah:

```bash
java -version
javac -version
```

Pastikan terminal berada di direktori utama project, yaitu direktori yang berisi folder `ResponsiPBO`.

### 1. Compile

```bash
javac -d out ResponsiPBO/*.java
```

Perintah tersebut mengompilasi seluruh file Java dan menyimpan hasil kompilasi ke folder `out`.

### 2. Run

```bash
java -cp out ResponsiPBO.Main
```
